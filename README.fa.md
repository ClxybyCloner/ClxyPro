<h1 align="center">کلکسی‌پرو — کلاینت VPN اندروید</h1>

**کلکسی‌پرو (ClxyPro)** یک کلاینت VPN سریع، مدرن و چندموتوره برای اندروید است
که با Kotlin و Jetpack Compose نوشته شده. این ریپو هم **سورس‌کد** برنامه است و
هم **کانال رسمی انتشار**: هر نسخه این‌جا با GitHub Actions بیلد می‌شود و
آپدیتر داخل برنامه همین ریپو را چک می‌کند — پس اگه کلکسی‌پرو را داری، همیشه با
یک تپ به جدیدترین نسخه می‌رسی.

## ⚡ چرا کلکسی‌پرو

- 🌍 **اینترنت باز، توی جیبت** — سایت‌ها و سرویس‌هایی که توی منطقه‌ت محدود شدن را باز کن. یک تپ بزن و وارد شو.
- 🔀 **دو موتور، هر مسیر را که بخوای** — **کلکسی هایپر (CLXY Hyper)** با حساب کاربری‌ت کار می‌کند، **کلکسی کوانتوم (CLXY Quantum)** با تونل MASQUE. هر وقت خواستی عوضش کن.
- 🔒 **ترافیکت مال خودته** — تونل VPN رمزگذاری‌شده برای کل گوشی، با امکان انتخاب برنامه‌هایی که از تونل رد بشن یا نشن.
- 👆 **تایل تنظیمات سریع** — مستقیم از نوار اعلان وصل یا قطع شو، بدون باز کردن برنامه.
- 👨‍👩‍👧 **یک اتصال برای همه** — تونل را با دستگاه‌های اطراف به اشتراک بذار؛ روی هات‌اسپات به‌صورت پروکسی SOCKS5 (`1080`) و HTTP (`8080`).
- 🔄 **آپدیت داخل برنامه** — به‌محض انتشار نسخه جدید خبرت می‌کند، فایل درستِ گوشی‌ت را دانلود می‌کند و قبل از نصب ازت اجازه می‌گیرد. هیچ‌چیزی پشت سرت نصب نمی‌شود.
- 📳 **بی‌سروصدا** — موقع وصل‌شدن به‌جای صدا، فقط کوتاه می‌لرزد.
- 🪶 **سبک** — حدود ۱۳ مگابایت، روان روی اندروید ۸.۰ به بالا، حتی گوشی‌های قدیمی.

## 🛠️ چطور کار می‌کند

کلکسی‌پرو یک رابط Kotlin و Jetpack Compose را با موتورهای بومی (Native) ترکیب
می‌کند. رابط کاربری از طریق یک API محلی با موتورها صحبت می‌کند تا تنظیمات را
مدیریت کند و وضعیت اتصال را بخواند؛ ترافیک شبکه دست موتورهاست. هر دو موتور با
تونل MASQUE (RFC 9298) کار می‌کنند.

در حالت VPN، سرویس `VpnService` اندروید یک رابط TUN مجازی می‌سازد و کل گوشی را
از تونل رد می‌کند. در حالت پروکسی، VPN سراسری ساخته نمی‌شود و فقط یک پروکسی
محلی SOCKS5 (`1080`) و HTTP (`8080`) در اختیار برنامه‌ها قرار می‌گیرد. قوانین
هر برنامه مشخص می‌کنند کدام برنامه از تونل رد شود و کدام مستقیم وصل شود.

## نصب در ۶۰ ثانیه

1. **دانلود کن** — فایل APK را از لینک بالا بگیر.
2. **بازش کن** — اندروید ازت می‌خواهد «Install unknown apps» را برای مرورگرت مجاز کنی. یک بار اجازه بده.
3. **Install را بزن.** تمام شد.

بعد برنامه را باز کن: **هایپر** ازت می‌خواهد با حساب کلکسی وارد شوی (فقط توکن
ورود روی گوشی‌ت نگه داشته می‌شود، هرگز رمزت نه)، **کوانتوم** اولین بار که باهاش
وصل شوی یک سریال می‌خواهد.

## ❓ سوالات متداول

**سورس‌کد کجاست؟**
همین‌جا — این ریپو سورس عمومی برنامه است و هر انتشار از روی آن با GitHub
Actions بیلد می‌شود.

**نسخه قدیمی می‌خواهم.**
نسخه‌های قدیمی در [صفحه Releases](https://github.com/ClxybyCloner/ClxyPro/releases)
در دسترس‌اند.

**هایپر یا کوانتوم — کدوم را استفاده کنم؟**
هایپر با حساب کلکسی وارد می‌شود و راحت کار می‌کند. کوانتوم اولین بار سریال
می‌خواهد و بعد بدون حساب وصل می‌شود. هر دو را امتحان کن و هر کدوم روی شبکه‌ت
سریع‌تر بود همان را نگه دار.

**پروکسی هات‌اسپات رمز نمی‌خواهد — امنه؟**
پروکسی‌های SOCKS5 و HTTP هات‌اسپات عمداً رمز ندارند، پس **فقط روی هات‌اسپاتی که
بهش اعتماد داری روشنش کن** و وقتی کارت تمام شد خاموشش کن. هر کسی که به
هات‌اسپاتت وصل باشد می‌تواند ازشان استفاده کند.

**کلکسی‌پرو رمز من را نگه می‌دارد؟**
نه. هایپر فقط توکن ورود را نگه می‌دارد؛ رمزت هرگز روی گوشی ذخیره نمی‌شود.
