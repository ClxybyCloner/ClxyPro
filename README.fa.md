**کلکسی‌پرو (ClxyPro)** یک کلاینت قدرتمند، مدرن و چندموتوره برای سیستم‌عامل اندروید است.

## ویژگی‌های کلیدی
- **هسته‌های چندگانه (Multi-Engine Core)**: پشتیبانی یکپارچه از موتورهای سایفون (Psiphon)، تور (Tor obfs4)، اپن‌رنگ (OpenRung)، لنترن (Lantern)، اس‌اس‌تی‌پی (SSTP) و فایرفاکس وی‌پی‌ان.
- **رابط کاربری مدرن نئونی**: طراحی گلس‌مورفیسم جذاب، نقشه جهانی نقطه‌ای متحرک، سنجش پینگ بلادرنگ و دکمه اتصال هماهنگ با انیمیشن‌های روان.
- **تونل‌بندی اختصاصی (Split Tunneling)**: امکان انتخاب برنامه‌هایی که مستقیماً یا از داخل تونل امن عبور کنند.
- **اشتراک‌گذاری در شبکه محلی (LAN Share)**: اشتراک تونل امن به صورت پروکسی SOCKS5 و HTTP روی وای‌فای خانگی.
- **خروجی چندمعماری (Multi-ABI APK)**: بیلد خودکار بسته‌های مجزا برای `arm64-v8a` و `armeabi-v7a` و بسته سراسری Universal.
